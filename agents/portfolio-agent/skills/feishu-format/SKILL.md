# Portfolio Feishu Card Templates

## Daily Digest Card

### Header
Portfolio Update — [employee_name] — [active_project_count] projects

### Body
**Urgent** (if any urgent section exists)
- [project_name] — [health] — [recommendation]

**Needs Attention**
- [project_name] — [stage] — [summary]

**On Track**
- [project_name] — [stage] — brief status

### Footer Buttons
- [View Dashboard] — opens the portfolio dashboard
- [Details] — opens the full report

[recommendation — specific, actionable, with named resource]

- [Snooze 1 Week] — delays the next alert
