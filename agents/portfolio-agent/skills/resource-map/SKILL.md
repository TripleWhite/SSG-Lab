# Resource Map Skill — Accelerator Resource Catalog

## Purpose

Provide the portfolio-agent with a structured inventory of accelerator resources
so every recommendation can name the specific person, program, or asset that
unlocks the next step.

## Resource Categories

### People

| Role | What They Offer | When to Suggest |
|------|----------------|-----------------|
| Mentors | Domain expertise, network introductions | Project needs specific industry guidance |
| LPs / Investors | Follow-on funding, strategic partnerships | Project approaching fundraise or partnership stage |
| Alumni founders | Peer advice, shared experience | Project facing a problem a past cohort solved |
| Industry contacts | Customer intros, market validation | Project needs customer references or market access |

### Programs

| Program | Description | When to Suggest |
|---------|------------|-----------------|
| Demo Day prep | Pitch coaching, deck review, rehearsal slots | Project 4-6 weeks from Demo Day |
| Legal clinic | Startup legal fundamentals (incorporation, IP, contracts) | Project pre-incorporation or facing legal questions |
| Go-to-market support | Marketing strategy, PR, launch planning | Project ready to launch or expand |
| Technical review | Architecture review, security audit, scaling advice | Project facing technical scaling challenges |

### Assets

| Asset | Description | When to Suggest |
|-------|------------|-----------------|
| Office space | Co-working desk, meeting rooms | Project needs physical presence |
| Cloud credits | AWS/GCP/Azure credits | Project needs compute resources |
| Tool licenses | SaaS tools (analytics, design, dev tools) | Project needs specific software |
| Event access | Conference tickets, speaking slots | Project needs visibility or networking |

## Usage Rules

1. Always check this resource map before suggesting external help.
2. Name the specific resource, not just the category.
3. If no matching resource exists, say so — do not invent resources.
4. Prefer resources that have been successfully used by similar projects.
5. Note any resource constraints (limited slots, application deadlines).
